# 공지사항 게시판 → Google Sheet 연동 가이드

공지사항은 Google Sheet에 글을 추가하면 사이트(`/notices.html` 및 홈 미리보기)에 자동으로 표시됩니다.

## 1. 시트 만들기

새 Google Sheet(또는 기존 문서에 새 탭)를 만들고, **탭 이름을 `공지사항`** 으로 합니다.
1행에 아래 헤더를 그대로 입력하세요.

| 날짜 | 제목 | 내용 | 고정 | 이미지 |
|------|------|------|------|--------|
| 2026-09-05 | [중요] 고종완 원장 사칭 딥페이크 주의 안내 | 최근 사칭 영상이 유포되고 있습니다.\n주의 부탁드립니다. | Y | /images/notice/deepfake-notice.png |
| 2026-09-01 | 9월 경매 & NPL 입문과정 개강 안내 | 자세한 내용은 세미나 페이지를 확인하세요. | | |

- **날짜**: 예) `2026-09-05` (최신순으로 자동 정렬됩니다)
- **제목**: 목록에 보이는 제목
- **내용**: 상세 내용. 셀 안에서 줄바꿈은 **Alt + Enter**. `http://` 링크는 자동으로 클릭 가능해집니다.
- **고정**(선택): `Y` 를 넣으면 목록 맨 위에 "고정"으로 표시됩니다. 비워두면 일반 공지.
- **이미지**(선택): 공지 상세(모달)에서 **내용 위에 표시**되는 이미지 주소. 비워두면 이미지 없이 표시됩니다.

## 이미지 추가 방법

**이미지** 열에 이미지 주소를 넣으면 됩니다. 두 가지 방식이 가능합니다.

1. **홈페이지 저장소에 올린 이미지 (권장)**
   - 이미지 파일을 저장소 `images/notice/` 폴더에 올립니다.
     (GitHub 저장소 → `images/notice` 폴더 → **Add file → Upload files** 로 드래그해서 업로드)
   - **이미지** 열에는 `/images/notice/파일명.png` 처럼 경로를 적습니다.
     예) `/images/notice/2026-sept-notice.png`
2. **외부 공개 이미지 URL**
   - 누구나 볼 수 있는 이미지 주소(`https://...`)를 그대로 붙여넣습니다.
   - ⚠️ 구글 드라이브 공유 링크는 직접 표시가 잘 안 될 수 있으니, 위 1번 방식을 권장합니다.

> **여러 장**을 넣으려면 셀 안에서 줄바꿈(**Alt + Enter**)이나 쉼표로 주소를 나열하면 됩니다.
> 주소가 잘못됐거나 이미지를 못 불러오면 그 이미지만 자동으로 숨겨지고, 공지 글은 정상 표시됩니다.

## 2. 시트 공유 설정 (중요)

방문자가 읽을 수 있어야 하므로 공유를 열어줍니다.
1. 우측 상단 **공유** 클릭
2. **일반 액세스** → **링크가 있는 모든 사용자**
3. 역할 **뷰어(Viewer)** 로 설정 → 완료

> 공지 내용은 공개 정보이므로 뷰어 공유로 충분합니다. (편집 권한은 주지 않습니다.)
> ⚠️ 신청자 정보가 있는 세미나 시트와는 **다른 문서**를 쓰는 것을 권장합니다.

## 3. 스프레드시트 ID 알려주기

시트 주소에서 ID를 복사해 전달해 주세요. (제가 사이트에 연결합니다.)

```
https://docs.google.com/spreadsheets/d/★여기가_ID★/edit
```

연결 위치는 `js/notices.js` 상단입니다.

```javascript
var CFG = {
  sheetId: "여기에_스프레드시트_ID",
  sheetName: "공지사항",   // 탭 이름
  previewCount: 3         // 홈 미리보기 개수
};
```

## 운영

- 공지를 추가하려면 시트에 **행을 추가**하면 됩니다. (사이트 새로고침 시 반영)
- 공지를 내리려면 해당 **행을 삭제**하거나 제목을 비우면 됩니다.
- 별도 배포/코드 수정 없이 시트만으로 관리됩니다.
