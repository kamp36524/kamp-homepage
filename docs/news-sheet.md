# KAMP 소식 → Google Sheet 연동 가이드

`KAMP 소식`(`/news.html`)은 Google Sheet에 글을 추가하면 사이트에 **갤러리 카드**로 자동 표시됩니다.
강의 사진, 유튜브 동영상, 협약식 등을 올릴 수 있습니다.

## 1. 시트 만들기

새 Google Sheet(또는 기존 문서에 새 탭)를 만들고, **탭 이름을 `소식`** 으로 합니다.
1행에 아래 헤더를 그대로 입력하세요.

| 날짜 | 제목 | 분류 | 내용 | 이미지 | 동영상 |
|------|------|------|------|--------|--------|
| 2026-09-10 | 경매 입문과정 3주차 강의 현장 | 강의 | 열띤 강의 현장 스케치입니다. | /images/news/lecture-0910-1.jpg, /images/news/lecture-0910-2.jpg | https://youtu.be/영상ID |
| 2026-09-05 | ○○기관과 업무협약(MOU) 체결 | 협약식 | 협약식 관련 내용을 적습니다. | /images/news/mou-0905.jpg | |

- **날짜**: 예) `2026-09-10` (최신순으로 자동 정렬됩니다)
- **제목**: 카드와 상세에 보이는 제목
- **분류**(선택): 카테고리 배지 (예: `강의`, `협약식`, `이벤트`). 자유 입력.
- **내용**(선택): 상세 설명. 셀 안 줄바꿈은 **Alt + Enter**. `http://` 링크는 자동 연결.
- **이미지**(선택): 사진 주소. 줄바꿈/쉼표로 여러 장. **첫 번째 이미지가 카드 대표(썸네일)** 로 쓰입니다.
- **동영상**(선택): **유튜브 링크**. 줄바꿈/쉼표로 여러 개 가능.

> 사진·동영상이 모두 없으면 카드에 `KAMP` 로고 자리표시가 뜹니다.
> 동영상만 있고 사진이 없으면, **유튜브 영상 썸네일**이 카드 대표 이미지로 자동 표시됩니다.

## 2. 이미지 올리는 방법

**이미지** 열에는 이미지 주소를 넣습니다. 두 가지 방식이 가능합니다.

1. **홈페이지 저장소에 올린 이미지 (권장)**
   - 이미지 파일을 저장소 `images/news/` 폴더에 올립니다.
     (GitHub 저장소 → `images` 폴더 → **Add file → Upload files** 로 드래그. `news/파일명` 형태로 올리면 폴더가 생깁니다.)
   - **이미지** 열에는 `/images/news/파일명.jpg` 처럼 경로를 적습니다.
2. **외부 공개 이미지 URL**
   - 누구나 볼 수 있는 이미지 주소(`https://...`)를 그대로 붙여넣습니다.

> 주소가 잘못됐거나 못 불러오는 이미지는 자동으로 숨겨지고, 소식 글은 정상 표시됩니다.

## 3. 동영상(유튜브) 넣는 방법

1. 유튜브에 영상을 올립니다. (공개 또는 "일부 공개" 로 설정하면 홈페이지에서 재생됩니다)
2. 영상 주소를 **동영상** 열에 붙여넣습니다. 아래 어떤 형태든 인식합니다.
   - `https://youtu.be/영상ID`
   - `https://www.youtube.com/watch?v=영상ID`
   - `https://www.youtube.com/shorts/영상ID`
3. 상세창에서 바로 재생할 수 있는 플레이어로 표시됩니다. (카드에는 ▶ 아이콘이 붙습니다.)

## 4. 시트 공유 설정 (중요)

방문자가 읽을 수 있어야 하므로 공유를 열어줍니다.
1. 우측 상단 **공유** 클릭
2. **일반 액세스** → **링크가 있는 모든 사용자**
3. 역할 **뷰어(Viewer)** 로 설정 → 완료

> ⚠️ 신청자 개인정보가 있는 세미나/상담 시트와는 **다른 문서**를 쓰는 것을 권장합니다.
> 공지사항 시트와 같은 문서에 `소식` 탭만 추가해서 써도 됩니다.

## 5. 스프레드시트 ID 알려주기

시트 주소에서 ID를 복사해 전달해 주세요. (제가 사이트에 연결합니다.)

```
https://docs.google.com/spreadsheets/d/★여기가_ID★/edit
```

연결 위치는 `js/news.js` 상단입니다.

```javascript
var CFG = {
  sheetId: "여기에_스프레드시트_ID",
  sheetName: "소식"   // 탭 이름
};
```

> ID를 넣기 전에는 페이지에 "소식을 준비 중입니다." 로 표시됩니다.

## 운영

- 소식을 추가하려면 시트에 **행을 추가**하면 됩니다. (사이트 새로고침 시 반영)
- 소식을 내리려면 해당 **행을 삭제**하거나 제목을 비우면 됩니다.
- 별도 배포/코드 수정 없이 시트만으로 관리됩니다.
